# LocalSend Usage Guide

**LocalSend** is an open-source local area network file transfer tool that allows secure transmission of files and text between different devices without an internet connection.

## Resource Links

- [Official Website Download Page](https://localsend.org/download?os=windows)
- [LocalSend GitHub Project Homepage](https://github.com/localsend/localsend)

![LocalSend Official Website Screenshot](/cordova/local-offical.png)

## Features

- **Cross-platform Support**: Supports Windows, macOS, Linux, Android, iOS
- **Secure Encryption**: End-to-end encrypted transmission
- **LAN Transmission**: No internet connection required
- **Multiple File Transfer**: Supports batch sending of files
