解决 ： ⚠️ 注意：Cordova + Gradle + Java 都对非 ASCII 路径敏感。会导致处理中文文件名时行为异常

```bash
apt update && apt install -y locales
locale-gen en_US.UTF-8
export LC_ALL=en_US.UTF-8
locale
```
