# LocalSend 使用指南

**LocalSend** 是一个开源的局域网文件传输工具，允许在不同设备间安全地传输文件和文本，无需互联网连接。

## 资源链接

- [官方网站下载页面](https://localsend.org/zh-CN/download?os=windows)
- [LocalSend GitHub 项目主页](https://github.com/localsend/localsend)

![LocalSend 官方网站截图](/cordova/local-offical.png)

## 功能特性

- **跨平台支持**：支持 Windows、macOS、Linux、Android、iOS
- **安全加密**：端到端加密传输
- **局域网传输**：无需互联网连接
- **多文件传输**：支持批量发送文件
